# Procyon Touch Platform

Prototype only. Not for production use. Not a medical, legal, housing-compliance, emergency-response, tenant-screening, background-check, or caregiving platform.

Procyon Touch is a browser-based MVP prototype for demonstrating a structured live-in support and rent-exchange matching workflow. It shows homeowner intake, applicant intake, compatibility scoring, demo data loading, local data review, and JSON export.

## Live Demo

Open the prototype here:

https://laurenlittlewolf.github.io/Procyon-Touch-Platform/

## What This Prototype Demonstrates

- Homeowner intake
- Applicant intake
- Local demo data storage
- Compatibility scoring
- Operator-style matching dashboard
- JSON export for review or discussion
- Founder/investor-facing workflow concept

## Prototype Boundaries

This prototype is not:

- a production application
- a medical platform
- a legal advice tool
- a housing-compliance platform
- an emergency-response system
- a tenant-screening platform
- a background-check service
- a caregiving or home-care agency system

All entries should be mock data only.

## How To Use

1. Open the live demo link.
2. Click **Load demo data**.
3. Review the homeowner and applicant records.
4. Review the generated compatibility matches.
5. Optionally add mock homeowner or applicant records.
6. Optionally export the local demo data as JSON.
